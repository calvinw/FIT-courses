1. Fixing Issues in Prism Repos
How PRISM issues get fixed. An assigned issue moves to In Progress on the project board. An agent fixes it on its own branch, then a code owner merges the pull request, which closes the issue automatically.
2. Creating a New Issue in A Repo
Writes issue #34: create docs/calvinw.md saying “hello from Calvin W”, with a goal and acceptance criteria. After assigning it, tours the project board’s board and table views and outlines the flow: codespace, issue, branch, plan, fix, test, pull request.
3. Creating a Codespace on Main And Asking Agent for Issue
Starts a codespace on main, logs in to Claude Code, and asks for assigned issues. The agent finds #34 and, following AGENTS.md, offers to branch from an up-to-date main and write a plan first. Tip: one issue at a time.
4. Making the Issue Branch, Creating the Plan, Fixing the Bug
The agent creates the issue-34 branch and drafts a plan with the goal, acceptance criteria and testing steps. After approval it pushes the plan, then the fix. Anyone can push to branches other than main. The fix is checked on GitHub.
5. Opening the Pull Request to Merge Issue Branch
The agent opens a pull request. A code owner merges it on GitHub, closing #34, deleting the branch and moving the card to Done. The agent then switches to main, pulls and removes the local branch. The plan stays in plans/.

PRISM Product Graph Editor (Oct 26)

Playlist: PRISM Product Graph Editor · 8 videos
An eight-part tour of the Product Graph Editor, PRISM’s main web app. It covers where the app and engine live, the graph editor and its YAML files, then each results tab: inventory, impact analysis, process results, contribution tree and Sankey graphs, using the cotton fiber and jacket templates.
1. Introduction to Product Graph Editor
Where things live in the prism-lca org. The engine, life-cycle-assessment-mcp, is built on Brightway, runs on DigitalOcean, and has a REST API for the web app and an MCP for LLMs. The editor is JavaScript on GitHub Pages and rebuilds whenever main changes.
2. The Graph Editor - Structure Graph, Scaled Graph
Sign in with Google, pick a template, and explore the cotton fiber and jacket graphs. The structure graph shows how activities connect; the scaled graph shows the amounts needed for the functional unit. Also covers reference amounts, elementary and technosphere flows, and graph controls.
3. Product Graph Yaml Files
The Edit tab shows the model as a readable YAML file with the goal, functional unit, products, and each process’s inputs, outputs and emissions. The File menu loads templates, saves, downloads and uploads YAML files, shows edit history, and clears the session.
4. Inventory Results
Using the jacket graph, covers the global settings for decimal places and light or dark mode, then the LCA results summary: life cycle inventory totals and five TRACI impact scores. The Inventory tab lists total emissions and how much each process produces.
5. Impact Analysis
The Impact Analysis tab breaks each impact category down by processes then flows, or flows then processes. Characterization factors show how scores are calculated: for climate change, each kilogram of methane counts 25 times as much as CO2, and everything is summed.
6. Process Results
Process Results looks at one activity at a time. The top shows its inputs and outputs; the bottom shows its share of each impact score, split into upstream and direct. For example, fabric weaving contributes 75% of climate change and 54% of acidification.
7. Contribution Tree Analysis
The contribution tree drills down from the functional unit to find hotspots. For the jacket’s climate change score, fabric weaving gives 75%, zipper production 8% and jacket assembly itself about 16%. Each row shows direct and accumulated contributions.
8. Sankey Graphs
The Sankey tab shows contributions as line thickness, by impact category or by flow, with filters for the number of processes and minimum share. Each card shows direct and upstream amounts, and clicking an activity highlights everything feeding into it.

Life Cycle Assessment MCP Introduction (Jul 26)

Playlist: Life Cycle Assessment MCP Introduction · 4 videos
A four-part introduction to LCA using the Prism LCA MCP in Claude.ai and the cotton fiber case study. It covers installing the connector, product graphs and unit processes, running the LCA to get the inventory and scaling, and calculating TRACI 2.1 impact scores from characterization factors.
1. LCA Mcp Installation and Simple Cotton Fiber Case Study
Adds the LCA MCP to Claude.ai as a custom connector, lists its tools and the three mock case studies, and opens the cotton fiber product graph YAML. The structure graph introduces the functional unit, unit processes, and elementary flows: emissions and extractions.
2. Product Graphs, Unit Processes, Inventory for LCAs
Looks at the two cotton fiber unit processes one at a time, as they’d appear in a database like ecoinvent. Fertilizer production emits 3.5 kg of CO2 per kilogram; cotton farming needs 0.2 kg of fertilizer and 800 L of water per kilogram of fiber.
3. Running the LCA and Finding Inventory Results
Runs the LCA on the YAML file. The inventory totals each emission across processes: 1.5 kg CO2, 0.015 kg N2O, 0.01 kg NH3 and 800 L of water. The scaled graph shows activity levels, such as fertilizer production scaled by 0.2.
4. Impact Assessment Calculations
Turns the inventory into TRACI 2.1 impact scores by multiplying each emission by its characterization factor and adding them up. Global warming totals 5.97, mostly from N2O, which counts 283 times as much as CO2. Also covers acidification, eutrophication and particulate matter.

Three videos on checking the Prism LCA engine against OpenLCA. They tour the case studies in the lca-mock-tests repo, install OpenLCA, and import the cotton fiber case study to confirm it gives the same inventory and TRACI 2.1 impact scores as the Prism MCP.

Creates an empty OpenLCA database, imports the cotton fiber zip from the repo’s releases, and calculates the product system with TRACI. The inventory (CO2 total of 1.5) and all four impact scores match the Prism results. Also tours the contribution tree and Sankey diagram.
