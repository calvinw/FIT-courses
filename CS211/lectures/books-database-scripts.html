Books Database: Starter SQL Scripts

Fall 26

Author

Calvin Williamson, Science and Math

These scripts build a small books database. Copy each block (use the copy button in its top right corner) and paste it into the Dolt SQL workbench, then run it. Run the blocks in order.

1. Create the table

Each book has an id (the primary key), a title, an author, the year it was published, and a genre.

CREATE TABLE books (
  id int NOT NULL,
  title varchar(1023),
  author varchar(1023),
  year int,
  genre varchar(1023),
  PRIMARY KEY (id)
);

3. Save your work with a Dolt commit

Dolt keeps a history of your database, like Git does for files. This stages every changed table and commits it with a message.

CALL DOLT_ADD('-A');
CALL DOLT_COMMIT('-m', 'Create books table with classics');

6. Try some queries

All the books:

SELECT * FROM books;

Just the science fiction, oldest first:

SELECT title, author, year
FROM books
WHERE genre = 'Science Fiction'
ORDER BY year;

Books published before 1950:

SELECT title, year
FROM books
WHERE year < 1950
ORDER BY year;

How many books are in each genre:

SELECT genre, COUNT(*) AS num_books
FROM books
GROUP BY genre
ORDER BY num_books DESC;

7. Look at the history

The commits you made:

SELECT commit_hash, committer, message, date
FROM dolt_log;

Every row added, changed, or deleted in the books table, and which commit did it:

SELECT to_id, to_title, diff_type, to_commit
FROM dolt_diff_books;
