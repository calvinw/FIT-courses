Coffee Shop Database: Starter SQL Scripts

Fall 26

Author

Calvin Williamson, Science and Math

These scripts build a small coffee shop database with two tables: products and orders. Copy each block (use the copy button in its top right corner) and paste it into the Dolt online SQL editor, then run it. Run the blocks in order: orders refers to products, so products has to exist first.

1. Create the products table

Each menu item gets a unique product_id, which is the primary key. in_stock is 1 if the item is available and 0 if it isn’t.

CREATE TABLE products (
  product_id int NOT NULL,
  name varchar(255),
  category varchar(255),
  price decimal(10,2),
  in_stock tinyint,
  PRIMARY KEY (product_id)
);

3. Create the orders table

Each order records which product a customer bought, how many, and whether the order has been completed (1) or is still waiting (0). order_id is the primary key. product_id is a foreign key that points back to the products table.

CREATE TABLE orders (
  order_id int NOT NULL,
  product_id int NOT NULL,
  customer_name varchar(255),
  quantity int,
  order_date date,
  completed tinyint,
  PRIMARY KEY (order_id),
  FOREIGN KEY (product_id) REFERENCES products (product_id)
);

5. Try some queries

All the orders:

SELECT * FROM orders;

Each order with the product name and what it cost (price times quantity):

SELECT o.order_id, o.customer_name, p.name, o.quantity, p.price,
       p.price * o.quantity AS total
FROM orders o
JOIN products p ON o.product_id = p.product_id
ORDER BY o.order_id;

How much each customer spent:

SELECT o.customer_name, SUM(p.price * o.quantity) AS total_spent
FROM orders o
JOIN products p ON o.product_id = p.product_id
GROUP BY o.customer_name
ORDER BY total_spent DESC;

Orders that are still waiting to be made:

SELECT o.order_id, o.customer_name, p.name, o.quantity
FROM orders o
JOIN products p ON o.product_id = p.product_id
WHERE o.completed = 0;

Items sold in each category:

SELECT p.category, SUM(o.quantity) AS items_sold
FROM orders o
JOIN products p ON o.product_id = p.product_id
GROUP BY p.category
ORDER BY items_sold DESC;

Menu items nobody has ordered:

SELECT p.name, p.category
FROM products p
LEFT JOIN orders o ON p.product_id = o.product_id
WHERE o.order_id IS NULL;
