Engagement Database: Starter SQL Scripts

Fall 26

Author

Calvin Williamson, Science and Math

These scripts build a marketing engagement database from scratch. It tracks how users interact with a company’s marketing: which channel reached them (email, web, social, …), which campaign it was part of, and whether it led to a purchase (a conversion). It is a copy of the engagement database on DoltHub.

Copy each block (use the copy button in its top right corner), paste it into the Dolt online SQL editor, and run it. Run the blocks in order: interactions refers to users and channels, so they have to exist first.

1. Create the channels table

A channel is the way a user was reached. channel_id is the primary key.

CREATE TABLE channels (
  channel_id int NOT NULL,
  channel_name varchar(50) NOT NULL,
  PRIMARY KEY (channel_id)
);

user_id is the primary key.

CREATE TABLE users (
  user_id int NOT NULL,

  PRIMARY KEY (user_id)

5. Create the interactions table

Each interaction is one time a user was reached by a campaign. interaction_id is the primary key. user_id and channel_id are foreign keys that point back to the users and channels tables.

opened_email, clicked_link, and converted are 1 for yes and 0 for no. session_duration is in seconds. A NULL means no value was recorded.

CREATE TABLE interactions (
  interaction_id int NOT NULL,
  user_id int,
  channel_id int,
  campaign varchar(100),
  opened_email tinyint,
  clicked_link tinyint,
  session_duration int,
  pages_visited int,
  converted tinyint,
  PRIMARY KEY (interaction_id),
  FOREIGN KEY (user_id) REFERENCES users (user_id),
  FOREIGN KEY (channel_id) REFERENCES channels (channel_id)
);

7. Create the views

A view is a saved query that you can use like a table. These four calculate conversion rates: conversions divided by interactions, as a percent. Run each block separately.

Conversion rate for each channel:

CREATE VIEW conversion_rate_per_channel AS
SELECT
  c.channel_name,
  SUM(i.converted) AS total_conversions,
  COUNT(i.interaction_id) AS total_interactions,
  SUM(i.converted) * 100.0 / COUNT(i.interaction_id) AS conversion_rate
FROM interactions i
JOIN channels c ON i.channel_id = c.channel_id
GROUP BY c.channel_name
ORDER BY conversion_rate DESC;

Conversion rate for each campaign:

CREATE VIEW conversion_rate_per_campaign AS
SELECT
  campaign,
  SUM(converted) AS total_conversions,
  COUNT(*) AS total_interactions,
  SUM(converted) * 100.0 / COUNT(*) AS conversion_rate
FROM interactions
GROUP BY campaign
ORDER BY conversion_rate DESC;

Conversion rate for each customer:

CREATE VIEW conversion_rate_per_customer AS
SELECT
  u.name,
  SUM(i.converted) AS total_conversions,
  COUNT(i.interaction_id) AS total_interactions,
  SUM(i.converted) * 100.0 / COUNT(i.interaction_id) AS conversion_rate
FROM interactions i
JOIN users u ON i.user_id = u.user_id
GROUP BY u.name
ORDER BY conversion_rate DESC;

Total interactions for each user:

CREATE VIEW user_total_interactions AS
SELECT u.name, COUNT(i.interaction_id) AS total_interactions
FROM interactions i
JOIN users u ON i.user_id = u.user_id
GROUP BY u.name
ORDER BY total_interactions DESC;

8. Try some queries

Use a view like a table:

SELECT * FROM conversion_rate_per_channel;

Each interaction with the user’s name and the channel name:

SELECT i.interaction_id, u.name, c.channel_name, i.campaign, i.converted
FROM interactions i
JOIN users u ON i.user_id = u.user_id
JOIN channels c ON i.channel_id = c.channel_id
ORDER BY i.interaction_id;

The longest sessions:

SELECT interaction_id, user_id, campaign, session_duration, pages_visited
FROM interactions
WHERE session_duration IS NOT NULL
ORDER BY session_duration DESC
LIMIT 10;

Channels with no interactions at all. A LEFT JOIN keeps every channel, even ones with no matching rows in interactions:

SELECT c.channel_name, COUNT(i.interaction_id) AS num_interactions
FROM channels c
LEFT JOIN interactions i ON c.channel_id = i.channel_id
GROUP BY c.channel_name
ORDER BY num_interactions;
