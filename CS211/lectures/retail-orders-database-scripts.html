Retail Orders Database: Starter SQL Scripts

Fall 26

Author

Calvin Williamson, Science and Math

These scripts build a small retail orders database with three tables: customers, products, and orders. Copy each block (use the copy button in its top right corner) and paste it into the Dolt online SQL editor, then run it. Run the blocks in order: orders refers to the other two tables, so they have to exist first.

1. Create the customers table

Each customer gets a unique customer_id, which is the primary key.

CREATE TABLE customers (
  customer_id int NOT NULL,
  first_name varchar(255),
  last_name varchar(255),
  email varchar(255),
  PRIMARY KEY (customer_id)
);

Each product gets a unique product_id, which is the primary key.

  product_id int NOT NULL,

5. Create the orders table

Each order records who bought what and when. order_id is the primary key. customer_id and product_id are foreign keys that point back to the customers and products tables.

CREATE TABLE orders (
  order_id int NOT NULL,
  customer_id int NOT NULL,
  product_id int NOT NULL,
  order_date datetime,
  PRIMARY KEY (order_id),
  FOREIGN KEY (customer_id) REFERENCES customers (customer_id),
  FOREIGN KEY (product_id) REFERENCES products (product_id)
);

7. Try some queries

All the orders:

SELECT * FROM orders;

Each order with the customer’s name and the product they bought:

SELECT o.order_id, c.first_name, c.last_name, p.name, p.price, o.order_date
FROM orders o
JOIN customers c ON o.customer_id = c.customer_id
JOIN products p ON o.product_id = p.product_id
ORDER BY o.order_date;

How many orders each customer placed and how much they spent:

SELECT c.first_name, c.last_name, COUNT(*) AS num_orders, SUM(p.price) AS total_spent
FROM orders o
JOIN customers c ON o.customer_id = c.customer_id
JOIN products p ON o.product_id = p.product_id
GROUP BY c.customer_id, c.first_name, c.last_name
ORDER BY total_spent DESC;

How many times each product was ordered:

SELECT p.name, COUNT(*) AS times_ordered
FROM orders o
JOIN products p ON o.product_id = p.product_id
GROUP BY p.product_id, p.name
ORDER BY times_ordered DESC;

Customers who haven’t placed any orders:

SELECT c.first_name, c.last_name
FROM customers c
LEFT JOIN orders o ON c.customer_id = o.customer_id
WHERE o.order_id IS NULL;
