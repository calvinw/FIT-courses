Dolt Databases and the SQL Editor (Oct 26)

Playlist: Dolt Databases and the SQL Editor · 4 videos
Four videos that build a small coffee shop database on DoltHub by pasting SQL into the query editor. They describe the two tables, create and fill them, save a joined report as a view, and change a price on a branch before merging it back into main.
1. Description of Coffee Orders Database
A look at the database you’ll build: a products table and an orders table. Each has a primary key, and orders uses product_id as a foreign key, so a join can show product names in a report.
2. Creating the Coffee Shop Database on DoltHub using SQL Queries
Creates a public database on DoltHub, then pastes each SQL snippet from the starter page into the query editor: create the products table, add its rows, then do the same for orders. Every change needs Commit directly, and the ER diagram shows the link.
3. Creating and Saving a View in Dolt
Runs a starter query that joins orders to products to show each order with its product name and cost, then saves it with Create view and commits it. The saved view appears under Views, ready to run again like a report.
4. Creating a Branch in Dolt Database
Creates a change-price branch, edits the espresso price and commits it there, so main keeps the old price. A pull request then merges the branch into main, and the branch is deleted, which takes effect right away without a commit.

MCP Servers - Connectors (Sep 25)

Playlist: MCP Servers - Connectors · 3 videos
Three videos on MCP servers, which give LLMs tools and data. An introduction explains how a tool call works, then the Dolt database and Yahoo Finance MCPs for the business management benchmarks project are added to Claude.ai and Mistral’s chatbot as custom connectors.
1. Model Context Protocol (MCP) Introduction
What the Model Context Protocol is. Without tools, an LLM can only answer from its training. With MCP, the app (the client) calls a tool on an MCP server for the LLM, such as web search or email, and passes the result back as extra context.
2. Hooking Up Mcp Servers To Claude Web
Adds the Dolt database MCP to Claude.ai as a custom connector, allows its tools, and lists the tables in the business management benchmarks database before pulling Costco’s financials. Then adds a Yahoo Finance MCP and gets four years of Nike’s data.
3. Mistral AI Connectors
Adds the Dolt database MCP to Mistral’s chatbot, which now offers connectors on every plan. Turn on developer mode, add a custom connector, and watch for the name field, which is editable even though it doesn’t look it. Then enable its tools and test it.

Playlist: Intro Dolt Databases · 2 videos
Two short videos introducing DoltHub, a free host for open-source SQL databases that works like GitHub. Using a small coffee shop database, they cover tables, rows, primary and foreign keys, views, schemas and branches, and why branches suit working with LLMs.
1. Dolt Databases Part1
A tour of DoltHub and the coffee shop database. A database is a set of related tables, a bit like worksheets. Covers the ER diagram, columns and rows, primary keys, and how the orders table uses a foreign key to point to products.
