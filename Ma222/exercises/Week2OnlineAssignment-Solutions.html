Ex 1 Twitter Posts

Suppose the observational units for some data are Twitter posts. Say whether each of the following is a variable or not. If it is a variable, give its type. If it is categorical, also say whether it is binary.

Item Variable? Type Why
a) Number of words in the post Yes Quantitative It counts the words, and each post has its own value.
b) Number of days since the post Yes Quantitative It measures an amount of time for each post.
c) Number of retweets of the post Yes Quantitative It counts the retweets of each post.
d) Total number of posts by a person No – This describes a person, not a single post. It would be a variable if the observational units were Twitter users.
e) Average number of words for all posts by a certain user on a certain day No – This is one summary of many posts, not a value recorded for each post.
f) Whether or not a post has a reply to it Yes Categorical, binary Each post is Yes or No.
g) First word in the post Yes Categorical, not binary The first word is a category, and there are many possible words.
h) Whether or not the post uses any capital letters Yes Categorical, binary Each post is Yes or No.

Ex 3 Parameter vs Statistic

1) Time to return an item. We want to study how long customers wait, on average, to return something. We record 50 customers’ time to return an item (the number of days from buying something to returning it) and get an average of 7.5 days.

a) Population: All customers who return an item.

b) Sample: The 50 customers whose return times were recorded.

c) Parameter: The mean number of days to return an item for all customers who return something, \(\mu\). Its value is unknown.

d) Statistic: The mean number of days for the 50 sampled customers, \(\bar{x} = 7.5\) days.

2) Coke or Pepsi. We want to study whether people prefer Coke or Pepsi. We collect 123 responses that say Coke, 89 that say Pepsi, and 12 that say neither.

a) Population: All people whose soda preference we want to know.

b) Sample: The \(123 + 89 + 12 = 224\) people who responded.

c) Parameter: The proportion of all people who prefer Coke, \(p\). Its value is unknown. (The proportion of all people who prefer Pepsi, or who prefer neither, are also parameters of interest.)

d) Statistic: The proportion of the sample who prefer Coke:

\[ \hat{p} = \frac{123}{224} \approx 0.549 \ (54.9\%) \]

For Pepsi, \(\hat{p} = 89/224 \approx 0.397\) (39.7%). For neither, \(\hat{p} = 12/224 \approx 0.054\) (5.4%).
