# Standard Normal Areas Practice

Find each area under the standard normal curve. Use the standard normal table, or a spreadsheet with `NORMSDIST`. The same problems are in this spreadsheet: [NormalAreasPractice.xlsx](data/NormalAreasPractice.xlsx) (open it in Google Sheets with File → Import, or in Excel).

| Area | Spreadsheet formula |
|:--|:--|
| Left tail area | `=NORMSDIST(z)` |
| Right tail area | `=1.0-NORMSDIST(z)` |
| Area between $z_1$ and $z_2$ | `=NORMSDIST(z2)-NORMSDIST(z1)` |
